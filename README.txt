【拾憶者物語 離線資料包版】—— 放到 GitHub Pages 使用

檔案（全部放在同一層，也就是 repo 根目錄或同一個資料夾）：
  index.html、version.json、sw.js、assets/（4 個檔案）、7 個 bgm_*.mp3

步驟：
1. 把整包上傳到 GitHub repo。
2. repo → Settings → Pages → 選 Branch（main）/ root → Save。
3. 用 https://你的帳號.github.io/repo名稱/ 開啟遊戲（不是 github.com 的檔案頁，也不是 raw 連結）。
4. 第一次開啟會跳出「下載離線資料包？」提示，按「下載」即可（也可到 ⚙️ 設定手動下載）。
5. 之後沒網路，開同一個網址就能玩。離線時網址結尾要有斜線（.../repo名稱/），少了斜線的網址離線打不開；建議加入書籤或「加到主畫面」。

想改成「打開就自動下載、不詢問」：把 index.html 裡 AUTO_OFFLINE_DOWNLOAD 改成 true。
更新遊戲檔案後，有網路時開啟遊戲會自動更新離線副本；若換了 mp3，請到 ⚙️ 設定重新按一次下載。


【版本更新機制】
版本號以「發佈當天的日期」為準，格式 YYYYMMDD，例如 20261011。
同一天再次發佈，依序在後面加小寫英文字母：20261011a、20261011b、20261011c……（z 之後是 aa、ab……）。
比較時日期大的較新；同一天則 無字母 < a < b < c……。
每次發佈新版：index.html 裡的 APP_VERSION 與 version.json 裡的 version 必須改成同一個版本號，兩個檔案一起上傳。
玩家連網開啟遊戲時，會讀取網站上的 version.json：
  1. 如果網站版本比玩家目前的版本新 → 跳出「發現新版本」視窗，詢問是否更新。按「立即更新」才會更新（先自動存檔、抓取最新遊戲資料，完成後自動重新載入）；按「稍後再說」就先不更新，同一個分頁不會再問。
  2. 更新並重新載入後，如果玩家有下載過離線資料包，會詢問是否更新離線資料包（只更新有變動的檔案，音樂與圖檔沒變就不會重新下載）。
  3. 玩家也可以隨時到 ⚙️ 設定查看資料包版本、手動下載或更新。

【道具與劇情的連結】
背包裡的道具分兩種：
  🎫 通行證：拿到就會開啟部分地圖（任務鏈）。
     · 縣市任務鏈完成後會獲得通行證，開啟「下一條」任務鏈。
     · 每個區域的主線劇情通關，會獲得該區的通行證，開啟該區各縣市的「支線任務」。
  📜 劇情任務道具：沒有開啟地圖的功能。每個區域主線通關時，主角群會託你把它帶給另一位主角群。
     對方在你抵達的區域主線劇情中出場、寒暄之後，你會當場把東西遞給他（只在主線劇情裡交付，縣市的支線任務不會被道具突然觸發）。交出去之後道具會變成灰色（仍可點開看詳情）。
     交付完成後，對方所在區域各縣市的「路名任務鏈」會開啟；
     如果某個區域沒有託付送達，該區的「路名任務鏈」會在主線通關後直接開啟。

【地圖解鎖】
地圖預設是灰色的，點灰色的地方會顯示需要哪一張通行證與取得方式：
  · 起點區域（依你選的角色而定）一開始就開放，可以進入主線劇情。
  · 其他區域：需要「前一區」的通行證（前一區主線劇情通關時取得）。
  · 區域裡的各縣市：需要「本區」的通行證（本區主線劇情通關時取得），取得後各縣市地圖與支線任務一併解鎖。
  · 縣市裡的任務鏈：完成一條任務鏈會拿到通行證，用來開啟下一條（包含更多支線故事任務）。

【物品欄】
分成兩個分頁：
  🎫 通行證（解鎖地名故事）：按縣市分組，拿到就會解鎖部分任務鏈。
  📜 劇情道具（推動劇情）：依旅程順序列出主角群託付的東西，顯示待交付／已交付（灰色），可點開看詳情。
拿到道具時都會有對話：嚮導或區域同伴把通行證遞給你、主角群把託付之物交到你手上、交付時也有對話。

【背景音樂】
同一時間只會播放一首；快速切換畫面時，上一首會一併淡出停止。
挑戰模式：進入測驗後才會播放挑戰音樂，在分頁選單時是一般的大廳音樂。

【回到地圖／回到首頁】
遊戲中上方列有「🧭 地圖」（回到世界地圖，留在遊戲裡）與「🏠 首頁」（回到標題畫面）兩個按鈕。
沒有圖時，對話與人物頁會自動用 emoji 代替，不影響遊玩。

【答錯時的 NPC 對話】
主線劇情與縣市任務鏈的測驗答錯後，按下「請○○再說一次」，NPC 會先用自己的口吻回應（每位 NPC 各有 2 句：第一次答錯、再次答錯），
接著重播剛剛的介紹內容，主角依個性說一句「我會再聽仔細」，然後重新作答。這些台詞在 index.html 搜尋「WRONG_TALK」即可修改。
自由挑戰（限時、答錯不重答）不受影響。
