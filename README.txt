【拾憶者物語 離線資料包版】—— 放到 GitHub Pages 使用

檔案（全部放在同一層，也就是 repo 根目錄或同一個資料夾）：
  index.html、version.json、sw.js、assets/（4 個檔案）、7 個 bgm_*.mp3

步驟：
1. 把整包上傳到 GitHub repo。
2. repo → Settings → Pages → 選 Branch（main）/ root → Save。
3. 用 https://你的帳號.github.io/repo名稱/ 開啟遊戲（不是 github.com 的檔案頁，也不是 raw 連結）。
4. 第一次開啟會跳出「下載離線資料包？」提示，按「下載」即可（也可到 ⚙️ 設定手動下載）。
5. 之後沒網路，開同一個網址就能玩。離線時網址結尾要有斜線（.../repo名稱/），少了斜線的網址離線打不開；建議加入書籤或「加到主畫面」。

想改成「打開就自動下載、不詢問」：把 index.html 裡 AUTO_OFFLINE_DOWNLOAD 改成 true。
更新遊戲檔案後，有網路時開啟遊戲會自動更新離線副本；若換了 mp3，請到 ⚙️ 設定重新按一次下載。


【版本更新機制】
版本號是日期（例如 20261005），數字越大越新。
每次發佈新版：index.html 裡的 APP_VERSION 與 version.json 裡的 version 必須改成同一個數字，兩個檔案一起上傳。
玩家連網開啟遊戲時，會讀取網站上的 version.json：
  1. 如果網站版本比玩家目前的版本新 → 跳出「發現新版本」視窗，立即更新遊戲資料（先自動存檔），幾秒後自動重新載入套用新版。
  2. 重新載入後，如果玩家有下載過離線資料包，會詢問是否更新離線資料包（只更新有變動的檔案，音樂與圖檔沒變就不會重新下載）。
  3. 玩家也可以隨時到 ⚙️ 設定查看資料包版本、手動下載或更新。

【道具與劇情的連結】
1. 每個區域的主線劇情通關：獲得該區的一件道具，並開啟該區各縣市的「支線任務」。
2. 這件道具同時是主角群託你帶給另一位主角群的東西（託付任務）。帶著它走進對方的家鄉縣市，交付對話會自動開始；完成後，對方所在區域各縣市的「路名任務鏈」會開啟。
3. 如果某個區域沒有託付送達，該區的「路名任務鏈」會在主線通關後直接開啟。
4. 縣市裡的「主線任務鏈」，部分需要先持有道具（完成前面的任務鏈就會拿到）。
5. 挑戰模式：進入測驗後才會播放挑戰音樂，在分頁選單時是一般的大廳音樂。
